## 1) **Punto a Punto**

- El medio de transmisión conecta **solo a dos dispositivos**.
    
- Nadie más comparte el canal → es exclusivo.
    

👉 Ejemplos:

- Un cable USB entre tu PC y tu celular.
    
- Enlaces de fibra óptica dedicados.
    

✅ Ventaja: rendimiento máximo (todo el canal para vos).  
❌ Desventaja: caro si hay que conectar muchos nodos.

---

## 2) **Multipunto (o compartido)**

- Varios dispositivos **comparten el mismo medio físico**.
    
- Solo uno transmite a la vez → se necesitan **métodos de acceso** para evitar colisiones (ej: TDMA, CSMA, CDMA).
    

👉 Ejemplos:

- Una red Wi-Fi (varios dispositivos usan el aire como medio).
    
- Un bus CAN en un auto.
    
- Redes coaxiales antiguas (Ethernet 10Base2).
    

✅ Ventaja: más barato y escalable.  
❌ Desventaja: el rendimiento depende de cómo se reparten el canal.

# 📝 Comparación rápida

| Según uso del medio | ¿Quién usa el canal?            | Ejemplo práctico            |
| ------------------- | ------------------------------- | --------------------------- |
| **Punto a Punto**   | Solo 2 equipos, canal exclusivo | Fibra dedicada, cable USB   |
| **Multipunto**      | Varios equipos comparten canal  | Wi-Fi, bus CAN, red coaxial |
